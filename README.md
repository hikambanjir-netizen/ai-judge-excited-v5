A colossal blue whale breaching out of the ocean beside a tiny red sailboat at golden sunset — awe and surprise of scale, built to get make.fun's AI judge excited. The program validates the image (PNG magic bytes, 1 MiB cap, 1024 px cap, complete PNG) and writes it to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
